# NextGen-Train

This repository contains code for training models using the [NextGenFramework](https://github.com/aidotse/nextgen-framework) decentralized learning framework.

NOTE: This project is heavily coupled to Gitlab, and ported here as a reference only. Only the original repo [here](https://gitlab.mgmt.ai.se/nextgeninfra/nextgen-train) is maintained.
